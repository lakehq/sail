::: info
Here, we refer to configuration options by their names, such as `execution.batch_size`, but you can typically set these options via environment variables, such as `SAIL_EXECUTION__BATCH_SIZE`.
Refer to the [Configuration Guide](/guide/configuration/) for more information on how Sail configuration works in general.
Most of these options are experimental and may change in future versions.
The [configuration reference](/reference/configuration/) marks each experimental option.
:::
